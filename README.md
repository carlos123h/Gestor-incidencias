# Gestor de incidencias

Programa en C para el control básico de incidencias: alta, listado y cambio de estado. Ejercicio de aprendizaje.

## Qué hace

- **Introducir** una incidencia (id, prioridad).
- **Listar** todas las que hay en memoria, con su estado (ABIERTA / CERRADA).
- **Modificar el estado** de una incidencia a partir de su id (abrirla o cerrarla).
- **Salir**.

## Cómo compilarlo

```bash
gcc -o gestor gestor.c
```
