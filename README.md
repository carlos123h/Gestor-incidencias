# Gestor de incidencias

Programa en C para el control básico de incidencias: alta, listado y cambio de estado. Ejercicio de aprendizaje.

## Qué hace

## Qué hace

- **Introducir** una incidencia con id y prioridad.
- **Listar** todas las incidencias con su estado.
- **Modificar el estado** de una incidencia a partir de su id.
- **Mostrar un resumen** con el total de incidencias abiertas y cerradas.
- **Listar únicamente las incidencias abiertas**.
- **Salir**.

## Cómo compilarlo

```bash
gcc -o gestor gestor.c
```
